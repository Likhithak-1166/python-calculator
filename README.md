# Python Calculator

A simple command-line calculator built using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Invalid operation validation
- Division by zero handling

## Concepts Used

- Variables
- Input and output
- Lists
- If-elif-else
- While loop
- Arithmetic operators
- Membership operator

## How to Run

```bash
python calculator.py
